# OpenGovAfrica-CPI-Governance-Analysis-Across-Africa
Interactive Excel dashboard analyzing CPI 2025 governance and transparency indicators across 54 African countries. Developed using Pivot Tables, Power Query, KPI cards, slicers, and data visualization techniques as a contribution to OpenGovAfrica by Jeisson Rojas.

# Objective of the Analysis

This project was developed as a contribution to OpenGovAfrica with the objective of analyzing transparency, governance quality, and corruption perception trends across African countries using the CPI 2025 dataset and governance-related indicators.

The analysis focuses on identifying:

-governance performance patterns,
-corruption risk levels,
-regional differences across Africa,
-and the relationship between rule of law and transparency indicators.

# Project Description

The dashboard provides an interactive overview of governance and transparency indicators across 54 African countries.

Using Excel dashboards, pivot tables, slicers, KPI cards, and data visualization techniques, the project explores:

/top and bottom CPI-performing countries,
/governance category distribution,
/CPIA governance performance,
/rule of law relationships,
/and regional governance patterns across SSA and MENA regions.

The dashboard was designed to support data storytelling and simplify governance insights for public transparency discussions.

# Key Insights

Countries with stronger rule of law indicators tend to achieve higher CPI transparency scores.
Nearly half of the analyzed African countries fall into the High Corruption Risk category.
Southern African and island nations generally showed stronger governance performance.
Significant governance disparities remain between countries across the continent.
Governance indicators and transparency scores demonstrate visible positive correlations.
Conclusions

This analysis highlights the importance of governance quality, institutional transparency, and accountability mechanisms in shaping public trust and national performance across Africa.

The dashboard demonstrates how data analytics and visualization can support public governance discussions and simplify complex governance indicators into accessible insights.

The project also showcases how Excel can be effectively used for governance analytics, interactive dashboards, and public-sector data storytelling.
